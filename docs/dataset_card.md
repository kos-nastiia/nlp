1. Назва проєкту
Система автоматичного виявлення тематичних категорій у неструктурованих текстах звернень громадян.


2. Задача (D)
Тип: Кластеризація та пошук дублікатів.
Input: Сирий текст звернення/відгуку українською мовою.
Output: Приналежність до автоматично визначеного тематичного кластера (без заздалегідь визначених міток).


3. Джерело даних
Відкритий набір даних Survey_responses_18k.csv, що містить результати опитувань та коментарі користувачів щодо сервісів, технологій та благоустрою. https://www.kaggle.com/datasets/annzhukova340/data-set-for-detailed-questions-from-surveys


4. Обсяг
Початковий розмір: 18310 рядків.
Після фільтрації: 9522 унікальних текстів.


5. Мова та домени
Мова: Українська (UA).
Тематика: Мультидоменна (IT, медицина, сфера послуг, саморозвиток).


6. Очищення та нормалізація (Preprocessing Policy — Lab 2)
Пайплайн реалізовано як детермінований модуль src/preprocess.py з наступними етапами:

Технічна чистка (Clean): Видалення зайвих пробілів, уніфікація апострофів (', ’, ‘, \`` -> '`).

Анонімізація (Mask PII): Автоматичне маскування регулярними виразами URL-адрес, Email та номерів телефонів (заміна на токени <URL>, <EMAIL>, <PHONE>).

Сегментація (Sentence Split): Розбиття довгих звернень на окремі речення за знаками пунктуації [.!?]. У результуючому файлі речення розділені символом |.

Лінгвістична нормалізація: Приведення всього тексту до нижнього регістру (Lowercasing) та видалення пунктуації (крім кутових дужок масок).

Аудит якості: Контроль середньої довжини (10.5 слів / 79.8 симв.) та відсів коротких неінформативних повідомлень (<5 слів).


7. Ризики та обмеження
Втрата семантики через Lowercasing: Переведення в нижній регістр може ускладнити розпізнавання власних назв або абревіатур, які важливі для специфічних кластерів.

Надлишкові дублікати: Після нормалізації (видалення пунктуації та регістру) кількість ідентичних рядків може зрости, що потребує повторної дедуплікації для чистоти кластерів.

Складність Sentence Splitting: В українській мові скорочення (напр., "вул.", "грн.") можуть помилково сприйматися як кінець речення, що розриває логічний зв'язок.

Агресивна чистка: Видалення всієї пунктуації може змінити емоційне забарвлення тексту (наприклад, зникнення знаків питання в скаргах), що є ризиком для подальшого Sentiment Analysis (якщо він знадобиться).

No Ground Truth: Оцінка якості кластеризації залишається суб'єктивною та вимагає Silhouette Score.


8. План наступного кроку (Lab 3)
Лематизація: Зведення слів до початкової форми (наприклад, через pymorphy3 або Stanza) для усунення впливу відмінків.
Векторизація: Перетворення нормалізованого тексту у вектори за допомогою TF-IDF або Sentence Embeddings.
Візуалізація: Використання алгоритмів зменшення розмірності (PCA/t-SNE) для візуального аналізу сформованих груп.


9. Розподіл даних та витоки (Splits & Leakage — Lab 5)
Для забезпечення чесної оцінки моделей дані було розділено на три спліти (Train/Val/Test) у пропорції 80/10/10 за допомогою стратегії Stratified Random Split (seed=42).

* **Ризик дублювання (Exact/Near Duplicates):** Проведено аудит на наявність точних та майже ідентичних (cosine similarity > 0.95) речень між сплітами. Виявлені дублікати задокументовані в `leakage_risk_report_lab5.md`, що дозволяє уникнути штучного завищення метрик через "запам'ятовування" тесту під час навчання.
* **Методологічна чистота (ML Discipline):** Впроваджено використання `sklearn.pipeline`, що гарантує виконання операції `fit` (наприклад, для TF-IDF векторизатора) виключно на тренувальній вибірці. Це запобігає витоку словника (vocabulary leakage) з валідаційних та тестових даних.
* **Відсутність метаданих для групування:** Оскільки поточна версія датасету не містить ідентифікаторів авторів (`user_id`) або часових міток (`date`), існує теоретичний ризик «групового витоку», коли різні речення одного автора можуть потрапити в різні спліти. На даному етапі цей ризик вважається прийнятним, але потребує моніторингу при додаванні метаданих.
* **Контроль шаблонів (Template Leakage):** Виконано перевірку на наявність технічних артефактів (напр. системних міток кластерів або залишків анонімізації), які могли б слугувати "підказками" для моделі замість реального семантичного аналізу тексту.


10. Результати Baseline-класифікації (Lab 6)

На основі розробленого пайплайну було проведено тестування базового класифікатора для перевірки придатності даних `processed_v2` до автоматичного аналізу.

### Технічна конфігурація
* **Classification Baseline:** Логістична регресія (`LogisticRegression`) з автоматичним балансуванням ваг класів (`class_weight='balanced'`).
* **Використані фічі:**
    * **Дані:** Очищений текст `processed_v2.csv` (із вилученням міток-підказок з тексту).
    * **Векторизація:** TF-IDF з використанням уніграм та біграм (`ngram_range=(1,2)`).
    * **Параметри:** `sublinear_tf=True`, `max_iter=500`.

### Метрики та прогрес
| Метрика | Baseline 1 (Unigrams) | Baseline 2 (Uni+Bigrams) | Приріст |
| :--- | :---: | :---: | :---: |
| **Accuracy** | 0.8528 | 0.8968 | +4.40% |
| **Macro-F1** | 0.8445 | 0.8944 | **+5.91%** |

### Оновлений реєстр ризиків (на основі Error Analysis)
1.  **Overlap класів (Високий):** Тексти, що описують складні соціальні явища (наприклад, відтік кадрів або діяльність органів), мають лексичні ознаки обох категорій, що створює "сіру зону" для лінійного класифікатора.
2.  **Noisy Labels (Середній):** Виявлено короткі звернення (до 5 слів), де мітка в оригінальному датасеті виглядає суперечливою через критичний брак контексту.
3.  **Складні заперечення (Технічний):** Модель демонструє гіперчутливість до частки "не". У випадках, коли "не" описує перевагу (наприклад, *"шнур не заважає"*), класифікатор помилково відносить текст до негативного класу.
4.  **Специфічний лексикон (Drift Risk):** Модель показує нестабільні результати на рідкісних термінах з вузьких доменів (ЖКГ, специфічне ПЗ), що вказує на потребу в лематизації для кращої генералізації.

### Наступні кроки
* Впровадження **лематизації** (`lemma_text` з ЛР3) для об'єднання різних форм одного слова в одну ознаку.
* Тюнінг списку **Stop-words** для зменшення впливу часток, що не несуть тематичного навантаження, але збивають класифікатор.
