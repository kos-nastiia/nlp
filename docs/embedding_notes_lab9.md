## 5. П'ять кейсів «корисно / некорисно»

### КЕЙС 1: `обладнання` — ✅ USEFUL
- **Тип:** domain/frequent
- **W2V сусіди:** запчастини, сучасне, застаріле, ремонту, фахівці
- **FT сусіди:** аналогічно + морфо-варіанти
- **Висновок:** Обидві моделі дають семантично логічних сусідів у темі ремонту/техніки. Embeddings реально корисні для кластеризації текстів цього домену.
- **Причина:** слово досить часте (~170 вжитків), чіткий тематичний контекст.

---

### КЕЙС 2: `завищені` — ✅ USEFUL
- **Тип:** domain/sentiment
- **W2V сусіди:** ціни, послуги, відповідають, порівняно
- **FT сусіди:** те саме + завищена, завищеними
- **Висновок:** Embeddings вловлюють сентиментальний контекст скарг на ціни. W2V стабільний завдяки достатній частоті (~110 вжитків).
- **Причина:** good semantic neighborhood — слово завжди у контексті критики цін.

---

### КЕЙС 3: `доставки` — ❌ WEAK
- **Тип:** domain/rare
- **W2V сусіди:** нестабільні (питної, води — вузький колокат)
- **FT сусіди:** трохи кращі через subword
- **Висновок:** Слово рідкісне (~40 вжитків) і зустрічається лише у вузькому контексті. Embeddings не дають реального доменного сигналу.
- **Причина:** замалий корпус + рідкісне слово.

---

### КЕЙС 4: `фахівців` — ⚠️ PARTLY
- **Тип:** domain/morph-variant
- **W2V сусіди:** нестабільні при freq~60
- **FT сусіди:** фахівці, кваліфікованих, некваліфікованих — логічно
- **Висновок:** Класичний кейс переваги FastText — subword «фахів-» пов'язує всі відмінкові форми. W2V бачить їх як різні слова.
- **Причина:** morphology helped (FT), rare word problem (W2V).

---

### КЕЙС 5: `персонал` — ⚠️ PARTLY
- **Тип:** domain/frequent
- **W2V сусіди:** привітний, уважний, завдяки
- **FT сусіди:** те саме + персоналу, персоналом
- **Висновок:** Embeddings показують тональний кластер (позитивні відгуки), але не доменний. Сусіди — загальні прикметники оцінки, не конкретні терміни.
- **Причина:** стилістичні сусіди замість змістових.

---

## 6. Порівняння Word2Vec vs FastText

| Сценарій | Результат | Пояснення |
|----------|-----------|-----------|
| Часті загальні слова | Рівні | Обидва мають достатньо прикладів |
| Морфологічні варіанти | FT кращий | Subword пов'язує відмінкові форми |
| Рідкісні слова (freq<100) | FT краще | W2V нестабільний |
| Доменні прикметники | W2V не гірше | Стабільний при великій частоті |
| OOV / опечатки | FT однозначно | W2V: KeyError; FT: завжди є вектор |

---

## 7. Головний висновок

**FastText є кращим вибором** для цього корпусу через:
1. **Морфологію** — українська мова багата на відмінки, FastText через subword пов'язує форми одного слова.
2. **Малий корпус** — ~119K токенів недостатньо для стабільного Word2Vec. FastText компенсує через subword n-grams.

**Практичне обмеження:** embeddings, навчені на цьому корпусі, мають низьку якість через малий розмір. Для production рекомендується pretrained FastText для укр. мови (facebook/fasttext-uk або lang-uk).

3 з 5 кейсів дали осмислених сусідів → embeddings **частково корисні** для аналізу доменної лексики.
