# Лабораторна робота №6: TF-IDF + Logistic Baseline

Дана робота присвячена побудові базового класифікатора для текстових даних на основі логістичної регресії та аналізу отриманих результатів.

## 1. Напрям проєкту
**Напрям D:** Кластеризація та дедуплікація звернень громадян.

## 2. Classification-підзадача
Груба тематична класифікація (Binary Classification) на основі розміченої підмножини даних `processed_v2.csv`. Основна мета — перевірити здатність лінійних моделей розрізняти контекстні категорії у неструктурованих текстах.

## 3. Baseline-варіанти
Було порівняно два підходи на основі `sklearn.pipeline`:
* **Baseline 1:** TF-IDF (Unigrams, `ngram_range=(1,1)`) + Logistic Regression (стандартні параметри).
* **Baseline 2:** TF-IDF (Uni+Bigrams, `ngram_range=(1,2)`) + Logistic Regression з використанням `class_weight='balanced'` для врахування дисбалансу класів.

## 4. Основні цифри (Test Set)
Результати порівняння на тестовій вибірці (15% від датасету):

| Метрика | Baseline 1 | Baseline 2 |
| :--- | :---: | :---: |
| **Accuracy** | 0.8528 | **0.8968** |
| **Macro-F1** | 0.8445 | **0.8944** |
| **Precision (Weighted)** | 0.8550 | **0.8980** |

Використання біграм та балансування ваг дозволило покращити Macro-F1 на **5.91%**.

## 5. Error Analysis та подальші кроки
Аналіз 10 помилкових кейсів показав наступне:
* **Проблема заперечень:** Модель часто плутає класи, коли частка "не" використовується у позитивному ключі (наприклад, *"шнур не заплутується"* маркується як негатив).
* **Семантичний overlap:** Складні звернення мають лексику, характерну для обох категорій одночасно.
* **Брак контексту:** Дуже короткі речення (до 5 слів) мають недостатньо ваги в TF-IDF для впевненого прогнозу.

**Що фіксити далі:** Впровадити **лематизацію** (з ЛР3), щоб об'єднати різні форми слів (наприклад, *"громади"*, *"громадою"*) в один токен. Це зменшить розрідженість словника та допоможе моделі краще узагальнювати рідкісні терміни.
