# Лабораторна робота №9: Word Embeddings — Word2Vec / FastText

## 1. Корпус
`processed_v2.csv` — звернення громадян (Напрям D).
~9 509 документів, ~119K токенів, середня довжина ~12.5 слів.

## 2. Моделі
- **Word2Vec** (skip-gram, gensim)
- **FastText** (skip-gram з subword, gensim)

## 3. Параметри
vector_size=100, window=5, min_count=3, sg=1, epochs=10, seed=42.
Однакові для обох — для чесного порівняння.

## 4. Типи слів, що аналізувались
- Часті доменні: сервіс, якості, обладнання
- Рідкісні доменні: фахівців, доставки
- Морфологічні варіанти: персоналу, обслуговуванні
- Доменні прикметники: завищені, сучасне
- Тематичні: навчання, персонал

## 5. Найцікавіші кейси
1. `обладнання` — ✅ USEFUL: обидва дають логічних технічних сусідів
2. `завищені` — ✅ USEFUL: W2V вловлює сентимент скарг на ціни
3. `доставки` — ❌ WEAK: рідке слово, нестабільні сусіди
4. `фахівців` — ⚠️ PARTLY: FT краще через subword морфологію
5. `персонал` — ⚠️ PARTLY: тональні, а не доменні сусіди

## 6. FastText краще / не краще
- **Краще:** морфологія (відмінки), рідкісні слова, OOV
- **Не краще:** часті стабільні слова — обидві моделі рівні

## 7. Чи embeddings корисні для корпусу
Частково. 3/5 кейсів осмислені. Корпус (~119K токенів) малий.
Для production — pretrained FastText (facebook/fasttext-uk).
