# Лабораторна робота №8: Topic Modeling — LSA / LDA

## 1. Який корпус аналізували
`processed_v2.csv` — очищений корпус звернень громадян (Напрям D).
Після фільтрації (>=5 слів): ~9 500 документів, середня довжина ~12.5 слів.

## 2. Які моделі запускали
- **LSA** — TF-IDF (1,2) + TruncatedSVD
- **LDA** — CountVectorizer (1,1) + LatentDirichletAllocation

## 3. Які k перевіряли
k = 5 та k = 8 для обох моделей.

## 4. Найкращі теми (LDA k=8)
| Topic | Назва | Якість |
|-------|-------|--------|
| T0 | Ціни, якість та ремонт | ✅ GOOD |
| T2 | Навчання та здоров'я | ✅ GOOD |
| T3 | Сервіс та атмосфера | ✅ GOOD |
| T4 | Асортимент послуг | ✅ GOOD |
| T5 | Доставка та замовлення | ✅ GOOD |

## 5. Погані теми
| Topic | Назва | Тип проблеми |
|-------|-------|-------------|
| LDA T6 | Загальна / змішана | mixed topic, garbage bin |
| LSA T6 | Стоп-слова / шаблони | template/style topic |
| LSA T7 | Дублікат обладнання | duplicate topic |

## 6. LSA vs LDA
LDA k=8 дала більш читабельні та менш дубльовані теми.
LSA корисніша для retrieval-задач, але при k=8 розщепила тему обладнання на дві.

## 7. Чи topic modeling корисний для цього корпусу?
Частково. 5 з 8 тем LDA читабельні та відповідають реальним доменам корпусу.
Головна складність — змішані домени (готелі, освіта, ремонт, ІТ) ускладнюють
чіткий розподіл при малому k. Рекомендується k=10–12 + lemma_text.
