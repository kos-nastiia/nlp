3. Правила обробки (Policy)
Пайплайн реалізовано у модулі src/preprocess.py:
Cleaning: Уніфікація апострофів, видалення зайвих пробілів.
Masking: Заміна URL, Email та телефонів на <URL>, <EMAIL>, <PHONE>.
Sentence Split: Розбиття тексту за знаками [.!?] (роздільник |).
Normalization: Нижній регістр (lower) та видалення пунктуації.

4. 5 найболючіших Edge Cases
Склеювання: Цифри в кінці речення (напр. ;1) злипаються зі словами.
Апострофи: Різні накреслення (',’) потребують уніфікації перед видаленням пунктуації.
Маски: Ризик видалення кутових дужок < > при очищенні тексту.

5. Результати "Після"
Довжина: Зросла з 10.5 до 12.5 слів (через коректний спліт та токенізацію очищених речень).
